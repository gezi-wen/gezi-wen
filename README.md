#### 相信的几件事

- **数据应该是你能打开看的东西**。所以我做的记忆、配置、状态一律落成纯文本文件 —— 出问题能自己 grep，不用等作者发新版本。
- **承诺要能被执行验证**。写进 README 的每条保证，背后得有一条会红的断言；做不到的事就明写「明确做不到」，比含糊其辞诚实。
- **不重复造轮子**。开工前先找现成的，能找到可靠的就不自己写。
